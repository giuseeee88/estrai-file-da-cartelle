# Estrazione file da cartelle
Questo progetto è nato con lo scopo di risolvere il problema dell'estrazione dei file nelle cartelle Windows. Ad esempio, se ho una directory con centinaia di sottodirectory, e devo ottenere in qualche modo i file sfusi all'interno delle varie sottodirectory è molto faticoso aprire ciascuna cartella e prendere i file all'interno. Questo programma nace proprio per risolvere questo problema, consente all'utente di selezionare le cartelle desiderate e tutti i file verranno inseriti all'interno di un'unica cartella sul desktop. Al momento funziona solo con Windows
